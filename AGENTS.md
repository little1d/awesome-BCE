# Maintaining awesome-BCE

Use README.md as the canonical index for future literature updates.

- Search by DOI and title before adding a paper. Prefer the published version.
- Read the primary paper to verify the prediction target, inputs, year and venue. Check code and dataset links against the authors' release.
- File each paper once under its main contribution. Use the resource table for reusable data and describe what it measures.
- Keep entries brief. Use an em dash for unverified code. Keep PDFs, reading notes and private drafts outside the repository.
