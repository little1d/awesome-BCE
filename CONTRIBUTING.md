# Contributing

Open a pull request editing README.md. Include a key method, reusable dataset or independent evaluation relevant to B-cell epitope prediction. In the PR, say which gap the entry fills.

For a paper, link its title to the publication, give its year and venue, and link the authors' code if available. For a dataset, link the official release and briefly describe its labels or evaluation task. Follow the existing table format and check for duplicates.
